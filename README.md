# Bear With Me: The Ready Kit

**Working tagline:** Life happens.

## The idea
A colorful, beginner-friendly car-care kit designed to help women feel more prepared when unfamiliar car situations arise. The prototype combines a customized organizer, practical tools, a small illustrated guidebook, and a QR-linked mobile guide.

## Semester MVP
- One customized compact organizer for sample vehicle documents, a tire-pressure gauge, flashlight, and guidebook.
- Two scenarios: checking tire pressure and understanding selected dashboard warning lights.
- A working QR-linked mobile website.
- A narrowly scoped experimental AI-assisted photo/description flow for selected dashboard symbols, with user confirmation, verified reference guidance, and a non-AI fallback.
- User testing in safely parked or simulated settings, followed by documented improvements.

**Out of scope:** mechanical diagnosis, claims that a vehicle is safe to drive, a complete roadside emergency kit, or multiple finished cases.
