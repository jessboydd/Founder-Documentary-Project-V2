# Website prototypes

- `index.html`: early placeholder page.
- `ask-the-bear.html`: "Ask the Bear" chat prototype (drafted 2026-10-13 with Claude). A person can snap, upload or describe a car problem and talk it through with the bear. It shows how urgent the problem is (Stop soon, Check soon, FYI) and has a red stop-soon banner whose safety steps are written into the page, not generated by the AI. Six dashboard lights have written-out facts and can be looked up without AI.

## How the AI part runs

The chat and photo help only work when the page is opened as a published Claude artifact: there it asks Claude through the artifact's `sample` capability, using the viewer's own Claude account. Opened anywhere else (GitHub Pages, a local file), the page shows only the dashboard-light lookup.

Live version: the "Ask the Bear" artifact in Jessica's Claude account (private until shared).

## Before testing with participants

- Have the light facts reviewed. They are in the `LIGHTS` list near the top of the page's script.
- Have the bear's rules reviewed. They are in the `rules()` function.
- Not yet tested with users. Photo sending has not been confirmed to work in every browser view.
- Needs an internet connection; the printed guidebook is the no-signal backup.
