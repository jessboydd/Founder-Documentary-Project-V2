# Usability test kit (draft)

Printable materials for the Scenario A (tire pressure / kit) and Scenario B (dashboard warnings / app) sessions in `../test-plan.md`. Drafted 2026-10-21 with Claude; **not yet reviewed or piloted**.

Print `bear-with-me-test-kit.pdf` on letter paper. Editable source: the "Bear With Me Test Kit" design canvas in Claude.

| Page | Use |
|---|---|
| 1 · Facilitator guide | Targets, pre-session checklist, safety rules, session flow, B-card order, timing, script |
| 2–3 · Scenario cards | 8 quarter-page cards (W warm-up, A1–A2 kit tasks, B1–B5 app tasks). Cut on the dashed lines |
| 4 · Answer key | Facilitator only: when to stop the clock, pass / auto-fail rules, what the bear should do |
| 5–6 · Score sheet | One double-sided sheet per participant |
| 7 · Results summary | Totals for P1–P8 against the 80% target, AI accuracy, confidence change, two design changes |
